JavaScript · Pre-Entrega 6: Funciones de Orden Superior

TechCore Hardware & PC

Simulador interactivo de tienda de hardware que integra la clase ProductoHardware, array de objetos y Funciones de Orden Superior: métodos de búsqueda (find, filter, some, forEach) y métodos de transformación y cálculo (map y reduce).

Operaciones con Funciones de Orden Superior en el Simulador

  • forEach: Recorre e imprime el catálogo de objetos y el detalle del carrito.
  • find: Localiza un componente específico por su id o nombre para comprar o consultar.
  • filter + some: Filtra componentes con stock disponible o según el presupuesto máximo del cliente.
  • map: Transforma el catálogo generando un nuevo array con precios con IVA incluido y precios promocionales.
  • reduce: Calcula tanto el valor total del inventario en almacén como el subtotal y total de unidades del carrito.

Instrucciones para revisar la entrega:

  1. Abre la Consola del Navegador (F12 o Cmd + Option + J en Mac).
  2. Utiliza el menú interactivo por prompt para filtrar por presupuesto (filter), buscar y comprar por ID/nombre (find), transformar lista con IVA (map) y finalizar compra (reduce).
